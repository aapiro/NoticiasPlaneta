# 001 — Requisitos no funcionales

Cada NFR es medible y se verifica en CI o en producción. Sin medición, no existe.

## Rendimiento

| ID | Requisito | Umbral | Cómo se mide |
|---|---|---|---|
| NFR-P1 | LCP portada en móvil 4G | < 2,5 s | Lighthouse CI |
| NFR-P2 | INP | < 200 ms | CrUX / RUM |
| NFR-P3 | CLS | < 0,1 | Lighthouse CI |
| NFR-P4 | p95 servidor en portada | < 300 ms | Micrometer + Prometheus |
| NFR-P5 | JS enviado al lector | < 30 KB gzip por página | presupuesto en CI |
| NFR-P6 | Coste IA por artículo | < 0,05 € | contador por job |

## Seguridad

| ID | Requisito |
|---|---|
| NFR-S1 | Todo `/admin/**` detrás de passkey + TOTP para CHIEF/ADMIN |
| NFR-S2 | Sesión server-side; prohibido JWT en almacenamiento del navegador |
| NFR-S3 | CSRF activo en todos los formularios; CSP con nonce, sin `unsafe-inline` |
| NFR-S4 | Subidas validadas por magic bytes y re-encodeadas antes de persistir |
| NFR-S5 | Secretos solo por variable de entorno; nunca en repo ni en logs |
| NFR-S6 | Toda escritura de agente queda en `audit_log` con `agent_id` |
| NFR-S7 | Contenido de fuentes tratado como datos, jamás como instrucciones |

## Disponibilidad

| ID | Requisito |
|---|---|
| NFR-A1 | El sitio público no depende de Hermes ni del módulo `ai` para servir HTML |
| NFR-A2 | RPO 15 min (WAL + snapshot), RTO 2 h |
| NFR-A3 | Degradación: si falla `search`, la portada sigue sirviendo con caché |

## Accesibilidad

| ID | Requisito |
|---|---|
| NFR-C1 | WCAG 2.2 AA en portada, artículo y panel editorial |
| NFR-C2 | Navegación completa por teclado, foco visible, sin trampas de foco |
| NFR-C3 | Alternativa textual en todo componente no textual (incluido el mapa) |
| NFR-C4 | Contraste mínimo 4,5:1 en texto normal |

## Calidad de código

| ID | Requisito |
|---|---|
| NFR-Q1 | Dominio sin anotaciones de Spring/JPA (verificado con ArchUnit) |
| NFR-Q2 | Mutation score >= 70% en `domain/` (PIT) |
| NFR-Q3 | Cobertura de ramas >= 90% en dominio y casos de uso |
| NFR-Q4 | Tests de persistencia con Testcontainers; prohibido H2 |
| NFR-Q5 | Cero `Thread.sleep` y cero `@Disabled` en la suite |
